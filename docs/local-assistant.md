# On-device assistant

Select **Settings → LandO assistant settings → Qwen (on device)**, download the model, then save. No AI key or LandO backend is required. Existing chats remain available; cloud keys remain in secure storage when switching providers. A missing/corrupt model disables chat until downloaded again, including after importing a backup on another phone.

The text-only model is Qwen3.5-0.8B, Unsloth Q4_K_M GGUF (532,517,120 bytes, about 508 MiB), Apache 2.0. It is downloaded from Hugging Face at pinned revision `6ab461498e2023f6e3c1baea90a8f0fe38ab64d0`, with SHA-256 `bd258782e35f7f458f8aced1adc053e6e92e89bc735ba3be89d38a06121dc517`. Downloads stream to a temporary file, verify size and digest, and rename into app-private support storage only on success. Existing verified weights are reused. Cancellation/failure removes unfinished downloads; a retry starts again. Model weights are excluded from LandO JSON exports and iCloud backups; Android app backup is disabled. Removal in AI settings reclaims storage without deleting conversations.

Inference uses llamadart / llama.cpp in a worker isolate, a bounded 8192-token context, a short recent conversation window, disabled thinking, 512 output tokens per round, at most four tool rounds, and a four-minute request deadline. CPU inference uses four threads for cross-device compatibility. It loads weights for a request and releases the native engine afterward. Smaller models have limited reasoning and instruction-following ability; app calculations are authoritative, while generated interpretations may be wrong. Very large layer summaries or old conversation turns are truncated for context limits. Only text is supported; images are not sent to this model.

**Query the internet** remains on by default. Explicit search and current-price questions require a real tool call; the local model writes the query using the conversation context. It can also call LandO's public DuckDuckGo HTML search tool when useful, with up to two searches per answer, four snippets per search, and a bounded response size. Only actual returned HTTPS links become stored research citations. Search results are untrusted reference material, not instructions. Ads are excluded. Search queries leave the device and may include user-supplied location/context; model inference and property calculations stay local. There is no paid search key or guaranteed service level: layout changes, challenges, rate limits, no connectivity or empty results can disable research. LandO never bypasses challenges. Failed searches are disclosed in the saved reply and do not block an otherwise local answer. Snippets are not verified contractor quotes, appraisals or exhaustive web research. Hosted provider search behavior is unchanged.

Native builds require Android API 24+ and iOS 16.4+. Apple uses the matching llamadart SwiftPM companion with its runtime privacy manifest. Only llama.cpp is bundled; model weights are downloaded separately. See [runtime Apple setup](https://llamadart.leehack.com/docs/platforms/apple-setup) and [model card](https://huggingface.co/unsloth/Qwen3.5-0.8B-GGUF).

Unit/widget tests run with `flutter test`. Real inference/download/search can be checked with `flutter test integration_test/qwen_on_device_test.dart -d SIMULATOR_OR_DEVICE_ID`; this downloads about 508 MiB if absent and uses an in-memory property repository without replacing user properties or AI settings. A macOS host `flutter test` cannot load the native runtime from the iOS SwiftPM companion; run the native test on an actual Flutter mobile target.

The iOS post-link phase strips Xcode’s absolute `PackageFrameworks` runtime search path from Runner and its debug dylib, retaining embedded-framework lookup and valid signatures. This avoids a confirmed simulator launch hang when the build lives under macOS-protected Documents; it does not change system privacy settings. Background: [upstream reproduction](https://github.com/skiptools/skip/issues/728).

Verified on 2026-11-05: real iOS simulator download/verification/reuse, key-free property conversation, and live Collierville fence-cost research returning four actual source links. These checks verify integration, not published-price accuracy. Static analysis and 102 unit/widget tests pass. Physical-device speed, memory and battery use still need device-specific acceptance testing.
