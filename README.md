LandO — Flutter Property Mapping & AI Land Planning App

Project Overview

Build a modern cross-platform Flutter application named LandO.

Tagline: Map it. Measure it. Plan it.

LandO is an interactive property mapping, land measurement, and AI-assisted planning application designed for property owners who want to measure land, visualize boundaries, and estimate improvement projects.

The application uses Google Maps satellite imagery, editable GPS coordinates, accurate geospatial calculations, and eventually the OpenAI API to help users plan projects such as driveways, fencing, land clearing, landscaping, and material purchases.

The app is online-first, with Google Maps as its primary interface. It is not intended to be an offline mapping application.
